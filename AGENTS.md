## Memory

Memory is stored in MEMORY.md; read it unconditionally at the beginning of every session. 

Every decision that is recorded should go into memory. MEMORY.md is a local-only, living document on this devbox: it is gitignored and must never be committed. Durable project decisions that other contributors need belong in `plans/IMPLEMENTATION_PLAN.md` or `README.md`; visual design decisions belong in `docs/DESIGN.md`.
