# Film assets

Stand-ins for what Windows draws, used only to render the demo film
(`website/media/film.html`); nothing here is deployed.

- `fonts/`: Selawik, Microsoft's open metric-compatible fallback for Segoe
  UI (SIL Open Font License 1.1, `fonts/OFL.txt`).
- `icons/`: Fluent UI System Icons, the open counterpart of the Segoe Fluent
  Icons glyphs smolcast draws (MIT, `icons/LICENSE`).
- `emoji/`: Fluent Emoji (Color), the designs behind Windows 11's Segoe UI
  Emoji (MIT, `emoji/LICENSE`). Named by code point.
- `stipple.svg`: the film's backdrop tile, a stipple of the app's own "s."
  mark from `public/favicon.svg`.
