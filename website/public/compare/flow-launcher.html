smolcast vs Flow Launcher

Flow Launcher is a mature, community-built launcher whose strength is its plugins and its file search, including file contents through Everything. smolcast builds in what Flow leaves to plugins (clipboard history, an emoji picker, snippets, unit conversions) and keeps to one 7 MB executable with no plugin system.

Checked against Flow Launcher's README and site (version 2.1.3) on 23 October 2026. Something out of date? Tell us.

Which one fits

Choose Flow Launcher if

  • You want plugins, or want to write your own in Python or JavaScript.
  • You use Everything and want file contents searched too.
  • You want browser bookmarks, shell commands and themes in the launcher.
  • You are on Windows 10.

Choose smolcast if

  • You want clipboard history, emoji and snippets built in, not assembled from plugins.
  • You want unit conversions with an answer that pastes on Enter.
  • You want one small executable with nothing else to install.
  • You prefer a fixed, small feature set to a plugin system.

Coming from Flow Launcher

  • Web searches become quicklinks: [quicklinks.<keyword>] with a {query} URL. Every search also ends with a row for your chosen engine.
  • Shell commands become tracked script files, each with an optional hotkey.
  • The hotkey is CtrlAltSpace by default, so it does not collide with Flow's AltSpace while you try both.

Everything else is in the configuration example and the full settings table.
