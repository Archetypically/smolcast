smolcast vs Raycast for Windows

Raycast for Windows is the fuller product: an extension store, AI, window management, notes and Cloud Sync with your Mac. smolcast covers the everyday core (apps, files, clipboard, emoji, snippets, calculator) in a 7 MB open-source executable with no account, no AI and no telemetry.

Checked against raycast.com/windows (version 2.9) and its pricing page on 23 October 2026. Something out of date? Tell us.

Which one fits

Choose Raycast if

  • You want extensions: Linear, GitHub, Notion, Slack, Spotify and hundreds more.
  • You want AI chat and AI commands in the launcher.
  • You want window management, notes or the game launcher.
  • You use Raycast on a Mac too, and want your setup synced.
  • You are on Windows 10.

Choose smolcast if

  • You want the core launcher features and nothing to sign in to.
  • You want one small executable whose source you can read, that uses no CPU while hidden.
  • You prefer settings in a text file you can keep in version control.
  • You want no AI features and no telemetry at all.

Coming from Raycast

  • Quicklinks become [quicklinks.<keyword>] tables in config.toml; {query} in the URL takes the text typed after the keyword, as in Raycast.
  • Snippets become [snippets.<id>] with a keyword. smolcast finds them by keyword in the palette but does not expand them as you type.
  • Script commands become tracked script files: Track Script File in the palette adds a .ps1, .cmd, .py or any program, with its own hotkey if you like.
  • The calculator pastes its answer on Enter, where Raycast copies it.

Everything else is in the configuration example and the full settings table.
