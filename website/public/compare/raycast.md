# smolcast vs Raycast for Windows

Raycast brings an extension store, AI and Mac sync. smolcast skips all three and fits in 7 MB with no account.

Updated 23 Oct 2026. Checked against [raycast.com/windows](https://www.raycast.com/windows) (v2.9). [Sources](https://smolcast.evanlee.engineer/compare/raycast#sources)

## smolcast

Open source

- Free
- Open source
- 7 MB
- No account

**Best for** the essentials, small and private

## Raycast for Windows

Raycast

- Free + Pro $10/mo
- Closed source
- Extensions
- AI

**Best for** extensions, AI and a Mac + PC setup

[Get Raycast for Windows](https://www.raycast.com/windows?ref=smolcast)

## Feature by feature

Bold marks where smolcast comes out ahead, and only where the other side publishes the fact.

|  | smolcast | Raycast for Windows |
| --- | --- | --- |
| **The basics** |  |  |
| Price | Free | Free; Pro $10/mo |
| Source | **Open source (MIT)** (the better pick) | Closed source (Extensions are open) |
| Runs on | Windows 11 | Windows 10 and 11, plus macOS |
| Account | **None** (the better pick) | Needed for Pro, AI and sync |
| Default hotkey | `Ctrl`+`Alt`+`Space` | Configurable |
| **Features** |  |  |
| Clipboard history | Built in (Text and images. Encrypted on disk) | Built in |
| Snippets | Built in (Find by name or keyword. No auto-expand) | Built in (Expands by keyword) |
| Emoji picker | Built in (Every emoji, in color) | Built in |
| File search | Built in (Through Windows Search) | Built in |
| Calculator | Built in (Units too. Enter pastes) | Built in |
| Quicklinks | Built in (Keywords with {query}) | Built in |
| Extensions | No (Scripts and quicklinks instead) | Raycast Store (Shared with the Mac app) |
| AI | No | Pro (Quick AI and AI Chat) |
| Window management | No | Built in |
| **Under the hood** |  |  |
| Download | 7 MB, one .exe (No installer) | Microsoft Store or WinGet (Size not published) |
| Idle | 0% CPU while hidden | Not published |
| Privacy | **No telemetry** ([One daily update check](https://smolcast.evanlee.engineer/privacy), can be turned off) (the better pick) | Collects usage data for analytics (Per its privacy policy) |

## Pick the one that fits

### Go with smolcast if

- You just want the essentials, fast
- You’d rather not make an account
- You like a small app you can read the code of
- You want zero AI and zero telemetry

### Go with Raycast if

- You want extensions (Linear, GitHub, Notion, Spotify…)
- You want AI right in the launcher
- You need window management
- You also use Raycast on a Mac
- You’re on Windows 10

[Get Raycast for Windows](https://www.raycast.com/windows?ref=smolcast)

On a Mac too? Tinycast is the free, open-source take on Raycast, and Alfred is the long-standing favorite: [smolcast vs Tinycast](https://smolcast.evanlee.engineer/compare/tinycast), [smolcast vs Alfred](https://smolcast.evanlee.engineer/compare/alfred).

## Coming from Raycast

- Quicklinks`[quicklinks.gh]` in `config.toml`, same `{query}` idea
- Snippets`[snippets.sig]` with a keyword. Found in the palette, not expanded as you type
- Script commands*Track Script File*: any `.ps1`, `.cmd`, `.py` or program, with its own hotkey
- CalculatorSame idea, but Enter pastes the answer instead of copying it
