smolcast vs Tinycast

Tinycast is macOS only, so if you are looking for Tinycast on Windows, smolcast is the closest thing: a free, open-source, native take on the same idea, with no accounts and no telemetry. It is a separate project with its own code, and it does less than Tinycast: no AI, extensions, window management or notes.

Checked against tinycast.dev (version 0.12.1) on 23 October 2026. Something out of date? Tell us.

Which one fits

Choose Tinycast if

  • You are on a Mac. smolcast does not run on macOS.
  • You want window management, floating notes, the calendar or dictation.
  • You want Raycast extensions or optional AI.

Choose smolcast if

  • You are on Windows 11 and want the same kind of launcher there.
  • You use Tinycast on a Mac and want a palette that feels familiar on your PC.
  • You want an MIT-licensed codebase.
  • You want a smaller feature set in a 7 MB executable.

Coming from Tinycast

  • Quicklinks carry over as [quicklinks.<keyword>] with {query}, the same idea as Tinycast's.
  • Snippets become [snippets.<id>] with a keyword; smolcast has no placeholders yet.
  • The hotkey defaults to CtrlAltSpace, the Windows reach of ⌥Space.

Everything else is in the configuration example and the full settings table.
