# smolcast vs Wox

Wox runs everywhere and does a lot, AI included. smolcast is Windows only, smaller, and stays out of AI.

Updated 23 Oct 2026. Checked against [woxlauncher.com](https://www.woxlauncher.com/) and [its repository](https://github.com/Wox-launcher/Wox) (v2.4.7). [Sources](https://smolcast.evanlee.engineer/compare/wox#sources)

## smolcast

Open source

- Windows 11
- Open source
- 8 MB
- No AI

**Best for** a small, quiet Windows launcher

## Wox

Open-source project

- Windows, Mac, Linux
- Open source
- Plugin store
- AI

**Best for** one launcher on every OS, with AI

[Get Wox](https://www.woxlauncher.com/?ref=smolcast)

## Feature by feature

Bold marks where smolcast comes out ahead, and only where the other side publishes the fact.

|  | smolcast | Wox |
| --- | --- | --- |
| **The basics** |  |  |
| Price | Free | Free |
| Source | Open source (MIT) | Open source (GPL-3.0) |
| Runs on | Windows 11 | Windows, macOS and Linux |
| Account | None | None; optional Cloud Sync |
| Default hotkey | `Ctrl`+`Alt`+`Space` | Not published |
| **Features** |  |  |
| Clipboard history | Built in (Text and images. Encrypted on disk) | Built in |
| Snippets | Built in (Find by name or keyword. No auto-expand) | Not listed |
| Emoji picker | Built in (Every emoji, in color) | Built in |
| File search | Built in (Through Windows Search) | Built in |
| Calculator | Built in (Units too. Enter pastes) | Built in (Plus a converter) |
| Quicklinks | Built in (Keywords with {query}) | Web search |
| Extensions | No (Scripts and quicklinks instead) | Plugin store (Node.js, Python or scripts) |
| AI | No | AI Chat |
| Window management | No | Window layouts |
| **Under the hood** |  |  |
| Download | 8 MB, one .exe (No installer) | WinGet, Scoop or Chocolatey (Size not published) |
| Idle | 0% CPU while hidden | About 150 MB of memory |
| Privacy | No telemetry ([One daily update check](https://smolcast.evanlee.engineer/privacy), can be turned off) | See the project |

## Pick the one that fits

### Go with smolcast if

- You’re on Windows 11 and want something small
- You want no AI at all
- You prefer the MIT license
- You want unit conversions that paste on Enter

### Go with Wox if

- You want the same launcher on Windows, Mac and Linux
- You want AI chat and AI commands
- You want notes, timers, screenshots and more
- You want a plugin store

[Get Wox](https://www.woxlauncher.com/?ref=smolcast)

Flow Launcher began as a fork of Wox: [smolcast vs Flow Launcher](https://smolcast.evanlee.engineer/compare/flow-launcher). Another open-source launcher for every OS: [smolcast vs Ueli](https://smolcast.evanlee.engineer/compare/ueli).
