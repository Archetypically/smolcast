smolcast vs PowerToys Command Palette

Command Palette, the successor to PowerToys Run, is Microsoft's launcher: free, open source, extensible, and deep in Windows itself, with WinGet, services, the registry and Settings pages. smolcast is narrower and smaller: a single 7 MB app with clipboard history, an emoji picker, snippets and unit conversions built in, and nothing else to install.

Checked against Microsoft's Command Palette documentation (updated October 2026) on 23 October 2026. Something out of date? Tell us.

Which one fits

Choose PowerToys Command Palette if

  • You already run PowerToys and want its utilities a keystroke away.
  • You want Windows administration in the launcher: WinGet installs, services, the registry, Settings pages, Terminal profiles, Remote Desktop.
  • You want community extensions, a Dock or window switching.
  • You are on Windows 10.

Choose smolcast if

  • You want clipboard history, emoji and snippets in the same palette, without extensions.
  • You want unit conversions (40cm to in) and an answer that pastes on Enter.
  • You want one small app rather than a suite.
  • You want no diagnostic data sent at all.

Coming from PowerToys Command Palette

  • Bookmarks become quicklinks: [quicklinks.<keyword>] with a URL, file or folder, and {query} for the text typed after the keyword.
  • The hotkey is CtrlAltSpace by default, so both can run side by side while you try smolcast.
  • Shell commands become tracked script files, each with an optional hotkey of its own.

Everything else is in the configuration example and the full settings table.
