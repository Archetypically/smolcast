# smolcast vs Keypirinha

Keypirinha is fast, portable and scriptable in Python, but its last release was in 2020. smolcast is new and still shipping.

Updated 23 Oct 2026. Checked against [keypirinha.com](https://keypirinha.com/) (v2.26, released November 2020). [Sources](https://smolcast.evanlee.engineer/compare/keypirinha#sources)

## smolcast

Open source

- Free
- Open source
- 7 MB
- Actively developed

**Best for** a launcher that still ships updates

## Keypirinha

Independent project

- Freeware
- Portable
- Python plugins
- Last release 2020

**Best for** a portable, scriptable launcher

[Get Keypirinha](https://keypirinha.com/?ref=smolcast)

## Feature by feature

Bold marks where smolcast comes out ahead, and only where the other side publishes the fact.

|  | smolcast | Keypirinha |
| --- | --- | --- |

## Pick the one that fits

### Go with smolcast if

- You want a launcher that’s still getting updates
- You want clipboard, emoji and snippets built in
- You want open source
- You want unit conversions

### Go with Keypirinha if

- You want a portable launcher
- You want to write plugins in Python
- You want to switch to running apps by name

[Get Keypirinha](https://keypirinha.com/?ref=smolcast)

Two plugin launchers that still ship updates: [smolcast vs Flow Launcher](https://smolcast.evanlee.engineer/compare/flow-launcher) and [smolcast vs Wox](https://smolcast.evanlee.engineer/compare/wox).

## Coming from Keypirinha

- Web searchesQuicklinks with a `{query}` URL
- Python pluginsTracked script files: a `.py` runs with its arguments and an optional hotkey
- Portablesmolcast is one .exe in any folder you can write to; settings live in `%APPDATA%`
