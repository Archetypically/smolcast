# Windows launcher alternatives, compared

smolcast and three alternatives, from one small app to a full extension platform.

Updated 23 Oct 2026. Checked against each project’s own site. smolcast is ours, so the [sources](https://smolcast.evanlee.engineer/compare/#sources) are below.

## smolcast

Open source

- Free
- Open source
- 7 MB
- No account

**Best for** the essentials, small and private

## Raycast for Windows

Raycast

- Free + Pro $10/mo
- Closed source
- Extensions
- AI

**Best for** extensions, AI and a Mac + PC setup

[Read the comparison](https://smolcast.evanlee.engineer/compare/raycast) · [Get Raycast for Windows](https://www.raycast.com/windows?ref=smolcast)

## PowerToys Command Palette

Microsoft

- Free
- Open source
- Part of PowerToys
- Extensions

**Best for** Windows admin and extensions

[Read the comparison](https://smolcast.evanlee.engineer/compare/powertoys-command-palette) · [Get PowerToys Command Palette](https://learn.microsoft.com/windows/powertoys/install?ref=smolcast)

## Flow Launcher

Open-source community

- Free
- Open source
- Plugins
- Everything search

**Best for** plugins and deep file search

[Read the comparison](https://smolcast.evanlee.engineer/compare/flow-launcher) · [Get Flow Launcher](https://www.flowlauncher.com/?ref=smolcast)

## Feature by feature

Bold marks where smolcast comes out ahead of all three, and only on published facts.

|  | smolcast | Raycast for Windows | PowerToys Command Palette | Flow Launcher |
| --- | --- | --- | --- | --- |
| **The basics** |  |  |  |  |
| Price | Free | Free; Pro $10/mo | Free | Free |
| Source | Open source (MIT) | Closed source (Extensions are open) | Open source (MIT) | Open source (MIT) |
| Runs on | Windows 11 | Windows 10 and 11, plus macOS | Windows 10 and 11 | Windows 10 and 11 |
| Account | None | Needed for Pro, AI and sync | None | None |
| **Features** |  |  |  |  |
| Clipboard history | Built in (Text and images. Encrypted on disk) | Built in | Built in (Recent entries) | Plugin |
| Snippets | Built in (Find by name or keyword. No auto-expand) | Built in (Expands by keyword) | No (Bookmarks with {query} instead) | No |
| Emoji picker | Built in (Every emoji, in color) | Built in | No (Windows has `Win`+`.`) | No |
| File search | Built in (Through Windows Search) | Built in | Built in | Built in (Names and contents, via Everything) |
| Calculator | Built in (Units too. Enter pastes) | Built in | Built in (Math and functions) | Built in (Copies the result) |
| Extensions | No (Scripts and quicklinks instead) | Raycast Store (Shared with the Mac app) | Extension Gallery | Plugin store (C#, Python, JS and more) |
| AI | No | Pro (Quick AI and AI Chat) | No | No |
| Window management | No | Built in | Window switching | No |
| **Under the hood** |  |  |  |  |
| Download | **7 MB, one .exe** (No installer) (the better pick) | Microsoft Store or WinGet (Size not published) | 309 MB installer (The whole PowerToys suite) | 97 MB installer |
