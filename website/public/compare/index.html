Command palettes for Windows, compared.

Four keyboard launchers for Windows, from a single small executable to a full extension platform. Each is good at something different; this page lays out what each one does, so you can pick by what you need.

Checked against each project's own site and documentation on 23 October 2026. smolcast is our project; corrections are welcome as issues.

In short

  • smolcast is the small one: the everyday core in a 7 MB executable for Windows 11, with no account, extensions, AI or telemetry.
  • Raycast for Windows is the full platform: extensions, AI, window management and sync with the Mac app, with a paid Pro plan.
  • PowerToys Command Palette is Microsoft's, and the deepest into Windows itself: WinGet, services, the registry and Settings, with extensions.
  • Flow Launcher is the community favorite for plugins and file search, including file contents through Everything.

On a Mac, Tinycast is the free, open-source counterpart to Raycast; smolcast is the closest thing to it on Windows.
