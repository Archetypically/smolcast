# smolcast vs Alfred

Alfred is Mac only. On Windows, smolcast gives you a launcher with clipboard history and snippets built in, free.

Updated 23 Oct 2026. Checked against [alfredapp.com](https://www.alfredapp.com/), its Powerpack page and help (v5.8.1). [Sources](https://smolcast.evanlee.engineer/compare/alfred#sources)

## smolcast

Open source

- Windows 11
- Free
- Open source
- 7 MB

**Best for** an Alfred-style launcher on Windows

## Alfred

Running with Crayons

- macOS
- Free + Powerpack £34
- Workflows
- Snippet expansion

**Best for** workflows and power features on a Mac

[Get Alfred](https://www.alfredapp.com/?ref=smolcast)

## Feature by feature

Bold marks where smolcast comes out ahead, and only where the other side publishes the fact.

|  | smolcast | Alfred |
| --- | --- | --- |
| **The basics** |  |  |
| Price | Free | Free; Powerpack £34 |
| Source | **Open source (MIT)** (the better pick) | Source not published |
| Runs on | Windows 11 | macOS 10.14 or later |
| Account | None | Not published |
| Default hotkey | `Ctrl`+`Alt`+`Space` | Configurable |
| **Features** |  |  |
| Clipboard history | **Built in** (Text and images. Encrypted on disk) (the better pick) | Powerpack |
| Snippets | **Built in** (Find by name or keyword. No auto-expand) (the better pick) | Powerpack (With text expansion) |
| Emoji picker | Built in (Every emoji, in color) | Not listed |
| File search | Built in (Through Windows Search) | Built in |
| Calculator | Built in (Units too. Enter pastes) | Built in |
| Quicklinks | Built in (Keywords with {query}) | Web search |
| Extensions | No (Scripts and quicklinks instead) | Workflows (Powerpack) |
| AI | No | Not listed |
| Window management | No | Not listed |
| **Under the hood** |  |  |
| Download | 7 MB, one .exe (No installer) | Mac app |
| Idle | 0% CPU while hidden | Not published |
| Privacy | No telemetry ([One daily update check](https://smolcast.evanlee.engineer/privacy), can be turned off) | See its policy |

## Pick the one that fits

### Go with smolcast if

- You’re on Windows 11
- You want clipboard history and snippets free
- You want an open-source launcher
- You want something tiny

### Go with Alfred if

- You’re on a Mac (smolcast isn’t)
- You want workflows
- You want snippets that expand as you type

[Get Alfred](https://www.alfredapp.com/?ref=smolcast)

The free, open-source Mac cousin is Tinycast, and Raycast now has a Windows app: [smolcast vs Tinycast](https://smolcast.evanlee.engineer/compare/tinycast), [smolcast vs Raycast for Windows](https://smolcast.evanlee.engineer/compare/raycast).
