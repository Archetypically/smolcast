# smolcast vs Flow Launcher

Flow Launcher grows with plugins and searches inside files through Everything. smolcast has no plugins and builds clipboard history, emoji and snippets in.

Updated 23 Oct 2026. Checked against [its README and releases](https://github.com/Flow-Launcher/Flow.Launcher) (v2.1.4). [Sources](https://smolcast.evanlee.engineer/compare/flow-launcher#sources)

## smolcast

Open source

- Free
- Open source
- 8 MB
- Batteries included

**Best for** built-in clipboard, emoji and snippets

## Flow Launcher

Open-source community

- Free
- Open source
- Plugins
- Everything search

**Best for** plugins and deep file search

[Get Flow Launcher](https://www.flowlauncher.com/?ref=smolcast)

## Feature by feature

Bold marks where smolcast comes out ahead, and only where the other side publishes the fact.

|  | smolcast | Flow Launcher |
| --- | --- | --- |
| **The basics** |  |  |
| Price | Free | Free |
| Source | Open source (MIT) | Open source (MIT) |
| Runs on | Windows 11 | Windows 10 and 11 |
| Account | None | None |
| Default hotkey | `Ctrl`+`Alt`+`Space` | `Alt`+`Space` |
| **Features** |  |  |
| Clipboard history | **Built in** (Text and images. Encrypted on disk) (the better pick) | Plugin |
| Snippets | **Built in** (Find by name or keyword. No auto-expand) (the better pick) | No |
| Emoji picker | **Built in** (Every emoji, in color) (the better pick) | No |
| File search | Built in (Through Windows Search) | Built in (Names and contents, via Everything) |
| Calculator | Built in (Units too. Enter pastes) | Built in (Copies the result) |
| Quicklinks | Built in (Keywords with {query}) | Web searches |
| Extensions | No (Scripts and quicklinks instead) | Plugin store (C#, Python, JS and more) |
| AI | No | No |
| Window management | No | No |
| **Under the hood** |  |  |
| Download | **8 MB, one .exe** (No installer) (the better pick) | 97 MB installer |
| Idle | 0% CPU while hidden | Not published |
| Privacy | No telemetry ([One daily update check](https://smolcast.evanlee.engineer/privacy), can be turned off) | See the project |

## Pick the one that fits

### Go with smolcast if

- You want clipboard, emoji and snippets out of the box
- You want unit conversions that paste on Enter
- You want one small .exe and nothing else
- You’d rather not manage plugins

### Go with Flow Launcher if

- You want plugins, or to write your own
- You use Everything and search inside files
- You want themes and browser bookmarks
- You’re on Windows 10

[Get Flow Launcher](https://www.flowlauncher.com/?ref=smolcast)

Flow Launcher began as a fork of Wox, which is still going: [smolcast vs Wox](https://smolcast.evanlee.engineer/compare/wox). Microsoft’s own launcher is next door: [smolcast vs PowerToys Command Palette](https://smolcast.evanlee.engineer/compare/powertoys-command-palette).

## Coming from Flow Launcher

- Web searchesQuicklinks with a `{query}` URL, and every search ends with your engine
- Shell commandsTracked script files, each with an optional hotkey
- Hotkey`Ctrl`+`Alt`+`Space` by default, so it won’t fight Flow’s `Alt`+`Space`
