# smolcast vs Listary

Listary finds files and points Open and Save dialogs straight at them. smolcast launches apps and pastes from clipboard history, emoji and snippets.

Updated 23 Oct 2026. Checked against [listary.com](https://www.listary.com/), its Pro page and its help. [Sources](https://smolcast.evanlee.engineer/compare/listary#sources)

## smolcast

Open source

- Free
- Open source
- 7 MB
- Launcher first

**Best for** a launcher with clipboard, emoji and snippets

## Listary

Little Carved

- Free + Pro $19.95
- Files first
- Quick Switch
- Double Ctrl

**Best for** finding files and taming Open and Save dialogs

[Get Listary](https://www.listary.com/?ref=smolcast)

## Pick the one that fits

### Go with smolcast if

- You want a launcher with clipboard, emoji and snippets
- You want a calculator with unit conversions
- You want everything free and open source
- You want one small .exe

### Go with Listary if

- You mostly search for files
- You want Open and Save dialogs to jump to your folders
- You like double-tapping Ctrl
- You need network-drive indexing (Pro)

[Get Listary](https://www.listary.com/?ref=smolcast)

For one search over files, tabs and windows, see [smolcast vs Fluent Search](https://smolcast.evanlee.engineer/compare/fluent-search); for Everything’s index in a launcher, [smolcast vs Flow Launcher](https://smolcast.evanlee.engineer/compare/flow-launcher).

## Coming from Listary

- File searchSearch Files: type, then Enter opens and Ctrl+Enter shows it in Explorer
- Web searchQuicklinks with a `{query}` URL, and a web search row after every query
- Hotkey`Ctrl`+`Alt`+`Space` by default, so it won’t clash with double Ctrl
