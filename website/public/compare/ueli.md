# smolcast vs Ueli

Ueli is an open-source Electron launcher for every OS. smolcast is native, Windows only, and about 25 times smaller.

Updated 23 Oct 2026. Checked against [its repository and releases](https://github.com/oliverschwendener/ueli) (v9.29.1). [Sources](https://smolcast.evanlee.engineer/compare/ueli#sources)

## smolcast

Open source

- Native
- Open source
- 7 MB
- Windows 11

**Best for** a native, tiny Windows launcher

## Ueli

Open-source project

- Electron
- Open source
- Windows, Mac, Linux
- Extensions

**Best for** one open-source launcher on every OS

[Get Ueli](https://ueli.app/?ref=smolcast)

## Feature by feature

Bold marks where smolcast comes out ahead, and only where the other side publishes the fact.

|  | smolcast | Ueli |
| --- | --- | --- |
| **The basics** |  |  |
| Price | Free | Free |
| Source | Open source (MIT) | Open source (MIT) |
| Runs on | Windows 11 | Windows, macOS and Linux |
| Account | None | None |
| Default hotkey | `Ctrl`+`Alt`+`Space` | `Alt`+`Space` |
| **Features** |  |  |
| Clipboard history | Built in (Text and images. Encrypted on disk) | Not listed |
| Snippets | Built in (Find by name or keyword. No auto-expand) | Not listed |
| Emoji picker | Built in (Every emoji, in color) | Not listed |
| File search | Built in (Through Windows Search) | Built in |
| Calculator | Built in (Units too. Enter pastes) | Built in (Plus currency conversion) |
| Quicklinks | Built in (Keywords with {query}) | Web search |
| Extensions | No (Scripts and quicklinks instead) | Extensions (Toggle on and off) |
| AI | No | Not listed |
| Window management | No | Not listed |
| **Under the hood** |  |  |
| Download | **7 MB, one .exe** (No installer) (the better pick) | 177 MB installer (Unsigned) |
| Idle | 0% CPU while hidden | Not published |
| Privacy | No telemetry ([One daily update check](https://smolcast.evanlee.engineer/privacy), can be turned off) | See the project |

## Pick the one that fits

### Go with smolcast if

- You want a native app, not Electron
- You want clipboard, emoji and snippets built in
- You want a 7 MB download
- You’re on Windows 11

### Go with Ueli if

- You want the same launcher on Windows, Mac and Linux
- You want currency conversion
- You like toggling extensions on and off

[Get Ueli](https://ueli.app/?ref=smolcast)

Another open-source launcher for every OS: [smolcast vs Wox](https://smolcast.evanlee.engineer/compare/wox). Raycast now runs on Windows and Mac: [smolcast vs Raycast for Windows](https://smolcast.evanlee.engineer/compare/raycast).

- Web searchQuicklinks with a `{query}` URL, and a web row after every search
- Hotkey`Ctrl`+`Alt`+`Space` by default, so it won’t fight Ueli’s `Alt`+`Space`
- CalculatorMath and unit conversions, offline; Enter pastes the answer
