# smolcast vs Tinycast

Tinycast is Mac only. smolcast is the same idea for Windows 11, its own project, and it does less.

Updated 23 Oct 2026. Checked against [tinycast.dev](https://tinycast.dev) (v0.12.1). [Sources](https://smolcast.evanlee.engineer/compare/tinycast#sources)

## smolcast

Open source

- Windows 11
- Open source
- 7 MB
- No account

**Best for** the Tinycast feel on Windows

## Tinycast

Open-source project

- macOS
- Open source
- No account
- Optional AI

**Best for** everything, on a Mac

[Get Tinycast](https://tinycast.dev/?ref=smolcast)

## Feature by feature

Bold marks where smolcast comes out ahead, and only where the other side publishes the fact.

|  | smolcast | Tinycast |
| --- | --- | --- |
| **The basics** |  |  |
| Price | Free | Free; tips welcome |
| Source | Open source (MIT) | Open source (AGPL-3.0) |
| Runs on | Windows 11 | macOS 26+ |
| Account | None | None |
| Default hotkey | `Ctrl`+`Alt`+`Space` | Configurable |
| **Features** |  |  |
| Clipboard history | Built in (Text and images. Encrypted on disk) | Built in (Also files and colors) |
| Snippets | Built in (Find by name or keyword. No auto-expand) | Built in (Markdown and placeholders) |
| Emoji picker | Built in (Every emoji, in color) | Built in (Plus symbols) |
| File search | Built in (Through Windows Search) | Built in |
| Calculator | Built in (Units too. Enter pastes) | Built in (Plus currency and time zones) |
| Quicklinks | Built in (Keywords with {query}) | Built in |
| Extensions | No (Scripts and quicklinks instead) | Raycast extensions (Off by default) |
| AI | No | Optional (Off by default) |
| Window management | No | Built in (35 commands, saved layouts) |
| **Under the hood** |  |  |
| Download | 7 MB, one .exe (No installer) | Mac app |
| Idle | 0% CPU while hidden | Under 100 MB of memory |
| Privacy | No telemetry ([One daily update check](https://smolcast.evanlee.engineer/privacy), can be turned off) | No telemetry |

## Pick the one that fits

### Go with smolcast if

- You’re on Windows 11
- You use Tinycast on a Mac and want the same feel on your PC
- You prefer the MIT license
- You want something tiny with fewer moving parts

### Go with Tinycast if

- You’re on a Mac (smolcast isn’t)
- You want window management, notes or calendar
- You want optional AI or Raycast extensions

[Get Tinycast](https://tinycast.dev/?ref=smolcast)

Tinycast borrows from Raycast, which now runs on Windows too: [smolcast vs Raycast for Windows](https://smolcast.evanlee.engineer/compare/raycast). On the Mac, Alfred is the long-standing favorite: [smolcast vs Alfred](https://smolcast.evanlee.engineer/compare/alfred).
