Privacy

smolcast collects nothing.

Everything the app keeps stays on your computer, and the only request it makes on its own is a daily update check you can turn off. This website sets no cookies and runs no analytics.

Updated 23 October 2026

The app

What it keeps, and where

Only these files, all under your own Windows profile. Delete the two folders and nothing is left.

%APPDATA%\smolcast\config.toml
Your settings, scripts, snippets and quicklinks.
%APPDATA%\smolcast\favorites.json
The results you pinned.
%LOCALAPPDATA%\smolcast\usage.json
How often and how recently you opened each result, to rank them.
%LOCALAPPDATA%\smolcast\clipboard\
smolcast's own clipboard history, encrypted, when it keeps one (below).
%LOCALAPPDATA%\smolcast\update.json
When it last checked for an update, and any version you chose to skip.

There is no account, no telemetry, no crash reporting and no log file. When something fails, the notice you see names the operation and an error code, never what you copied or typed.

The one request it makes on its own

Once a day smolcast asks GitHub for the latest release of Archetypically/smolcast at api.github.com. The request carries smolcast's version in its user agent and nothing about you. GitHub sees your IP address, as it does for any visit, under GitHub's privacy statement. A new version is downloaded only when you choose to install it.

To turn the check off, clear Check GitHub for a new version once a day in smolcast's settings, or set check_for_updates = false in config.toml.

Things that leave your computer only when you choose them

  • Web searches and quicklinks open in your browser when you pick them. The search engine or site you chose receives your query under its own policy.
  • File search asks the Windows Search index on your PC. smolcast keeps no index of its own.
  • Scripts run the programs you set up, with your permissions.

Clipboard history

  • When Windows clipboard history (WinV) is on, smolcast shows Windows' history and keeps no copy of its own.
  • Otherwise it keeps its own: the last 100 items by default, encrypted on disk with Windows' Data Protection API so that only your Windows account can read them. Set clipboard_persist = false to keep it in memory only, or clipboard_capture = false to record nothing.
  • It skips anything an app marks as excluded from clipboard history, which is how most password managers flag passwords. It cannot recognize a password that is not marked.

This website

  • No cookies, analytics or trackers. Every page, script, style, image and font comes from this site; nothing loads from anywhere else, and the site's Content Security Policy enforces that.
  • Your theme choice. If you switch between light and dark here, your browser remembers the choice in its local storage. It never leaves your browser.
  • Hosting. The site is served by Cloudflare Pages. Cloudflare handles each request, including your IP address and browser's user agent, to deliver and protect the site, under Cloudflare's privacy policy. No visitor analytics are turned on.
  • Downloads come from GitHub's release pages, under GitHub's privacy statement.
